# 蒲公英达人采集助手

这是一个 Chrome 浏览器插件，用于在小红书蒲公英“找博主/博主广场”筛选结果页，自动采集博主昵称、蒲公英博主 ID 和详情页链接，并导出 CSV 文件。

插件适合不会写代码的人使用。安装后，使用者只需要正常登录蒲公英、手动筛选博主，然后点击插件面板里的“开始采集”。

## 适用环境

- 推荐浏览器：Google Chrome
- 可用浏览器：Chrome 或 Chromium 内核浏览器，例如 Microsoft Edge
- 系统：macOS、Windows 均可
- 不需要安装 Python
- 不需要安装 Node.js
- 不需要打开命令行
- 需要能正常访问并登录小红书蒲公英后台

## 文件说明

交付时请使用整个文件夹：

```text
pgy-kol-collector
```

如果收到的是压缩包：

```text
pgy-kol-collector.zip
```

请先解压，再加载解压后的 `pgy-kol-collector` 文件夹。不要直接选择 zip 文件。

## 首次安装

1. 打开 Chrome。
2. 在地址栏输入：

```text
chrome://extensions/
```

3. 打开右上角的“开发者模式”。
4. 点击“加载未打包的扩展程序”。

有些 Chrome 版本会显示为：

```text
加载已解压的扩展程序
```

这两个按钮是同一个意思。

5. 选择解压后的 `pgy-kol-collector` 文件夹。
6. 页面中出现“蒲公英达人采集助手”，表示安装成功。

## 权限提示

插件会请求以下权限：

- 读取蒲公英页面内容
- 使用标签页能力
- 使用 debugger 调试能力

其中 `debugger` 权限是必要的。蒲公英页面的昵称点击不是普通网页链接，插件需要模拟真实鼠标点击昵称，才能打开博主详情页并拿到真实 URL 里的博主 ID。

如果 Chrome 提示：

```text
蒲公英达人采集助手已开始调试此浏览器
```

这是正常现象。采集结束后提示会自动消失。

## 使用流程

1. 打开蒲公英后台：

```text
https://pgy.xiaohongshu.com/solar/pre-trade/note/kol
```

2. 正常登录蒲公英。
3. 在页面里手动设置筛选条件。
4. 确认页面上已经显示筛选后的博主列表。
5. 页面右侧会出现“蒲公英采集助手”面板。
6. 设置参数：

```text
最大页数：本次最多采集多少页
每页最多：每页最多点击多少个博主，通常填 20
延迟ms：每一步等待时间，默认即可
```

7. 点击“开始采集”。
8. 插件会逐个点击当前页博主昵称，获取详情页 URL 中的博主 ID。
9. 当前页采集完成后，插件会点击底部分页的右箭头，进入下一页继续采集。
10. 采集结束后，点击“导出CSV”。

## 推荐参数

如果筛选结果是 76 位博主，每页 20 个，可以设置：

```text
最大页数：4
每页最多：20
延迟ms：1400
```

如果只想先测试第一页：

```text
最大页数：1
每页最多：20
延迟ms：1400
```

## 导出结果

导出的 CSV 可以用 Excel、WPS 或 Numbers 打开。

字段包括：

- `nickname`：博主昵称
- `blogger_id`：蒲公英博主 ID
- `blogger_url`：小红书主页链接，由 `https://www.xiaohongshu.com/user/profile/` 拼接 `blogger_id` 生成
- `province`：博主所在省/直辖市/地区；如果位置只有一个值，写入本字段
- `city`：博主所在市；如果位置只有一个值，本字段留空
- `tags`：博主标签，多个标签用 `|` 分隔
- `fans_count`：粉丝数，过万数据会转为纯数字，例如 `5.1w` 导出为 `51000`
- `read_median`：阅读中位数
- `interaction_median`：互动中位数
- `image_note_price`：图文笔记一口价
- `video_note_price`：视频笔记一口价
- `page_no`：采集时所在页
- `rank_in_page`：当前页内顺序
- `collected_at`：采集时间

其中 `image_note_price` 和 `video_note_price` 会优先从报价悬停弹层中读取；如果蒲公英列表直接展示对应报价列，也会按表头读取。

## 更新插件

如果收到新版 `pgy-kol-collector` 文件夹：

1. 替换旧文件夹，或放到一个新位置。
2. 打开：

```text
chrome://extensions/
```

3. 找到“蒲公英达人采集助手”。
4. 点击“重新加载”按钮。
5. 回到蒲公英页面，刷新页面。

注意：每次重新加载插件后，都需要刷新蒲公英页面，否则页面里可能还残留旧版本脚本。

## 常见问题

### 没有看到右侧采集面板

请检查：

- 是否已经加载 `pgy-kol-collector` 文件夹
- 当前页面是否是 `https://pgy.xiaohongshu.com/*`
- 是否刷新过蒲公英页面

### 点击开始后已采集数量不增加

请先确认：

- 当前页面有博主列表
- “每页最多”不是 0
- Chrome 允许插件使用 debugger 权限
- 页面没有被切到其他标签页

如果仍然不增加，请点击“诊断”，把复制出来的内容发给维护人员。

### 到某一页后停止，提示列表未加载或没有识别到博主

这通常是蒲公英翻页后页面短暂空白、列表加载较慢或网络波动导致。新版插件会自动多等一段时间并重试识别。

如果仍然停止，请先不要刷新页面，点击“诊断”，把复制出来的内容和当前页截图发给维护人员。

### 推荐数量和导出数量不一致

以页面实际给出的每页列表为准。蒲公英可能显示“推荐 76 位博主”，但某些筛选结果页实际渲染数量可能不是严格 20/20/20/16。插件采集的是页面上实际可点击到的博主。

### 采集过程中可以手动操作页面吗

不建议。

采集过程中请不要手动切换筛选条件、点击分页、刷新页面或关闭蒲公英页面，否则可能导致漏采或重复采集。

### 可以给别人电脑使用吗

可以。把整个 `pgy-kol-collector` 文件夹发给对方，对方按“首次安装”步骤加载即可。

对方电脑不需要安装代码环境，只需要 Chrome 和蒲公英账号。

## 使用注意

- 请只采集自己有权限访问的蒲公英后台数据。
- 不要在采集过程中修改筛选条件。
- 建议先用“最大页数 = 1”测试，确认导出正常后再采集多页。
- 如果蒲公英页面改版，可能需要更新插件选择器。
