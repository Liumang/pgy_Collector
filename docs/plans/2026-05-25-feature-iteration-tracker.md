## 2. 当前功能状态

### 2.1 Mac 桌面采集助手

当前桌面版已支持：

- 内置浏览器打开蒲公英找博主
- 授权码登录（正式链路保留；本地 Demo 版默认关闭）
- 当前列表采集
- 博主昵称上传采集
- 相似博主采集
- 常规采集
- 增强采集
- CSV 中文表头导出
- 采集完成后空值自检和一次补采
- 长时间无进展自动停止保护
- 本地数据库后台自动写入
- localhost 博主库筛选、备注和员工协作

当前版本：

- `desktop`：`0.2.3-demo`
- `data-console`：`0.2.0`

### 2.2 授权码生成器

当前授权码生成器已支持：

- 填客户名
- 选授权时长
- 指定生成数量
- 批量生成授权码
- 自动写入飞书多维表格
- 复制生成结果

当前版本：

- `license-generator`：`1.2.1`

后续口径：

- 本地授权码生成器进入历史保留状态
- 新授权码生成、激活记录、机器绑定、停用和重置，迁移到 `data-console` 的授权管理后台
- 客户本地 App 默认不显示授权管理入口，只有管理端开启 `PGY_LICENSE_ADMIN_ENABLED=1` 后显示

### 2.3 授权校验

当前授权链路：

1. 采集助手本地校验授权码签名
2. 读取当前机器码
3. 查询飞书多维表格中的授权码记录
4. 未激活则写入机器码、激活时间、IP、设备信息
5. 已激活且机器码一致则允许登录
6. 已激活且机器码不一致则拒绝登录

`0.2.0` 新增线上授权链路：

1. 管理端生成随机授权码，服务端只保存哈希和脱敏码
2. 采集助手配置 `PGY_LICENSE_API_URL` 后，不再本地验签，改为请求线上 `/api/licenses/activate`
3. 线上授权中心首次激活时绑定机器码
4. 同机器重复登录允许，不同机器使用同一授权码会拒绝
5. 授权中心记录激活、登录、拒绝、停用和重置机器绑定事件
6. 未配置 `PGY_LICENSE_API_URL` 时，桌面端继续沿用现有飞书授权链路，避免未部署服务器前无法使用

### 2.4 数据导出

当前导出仍以 CSV 为主。

导出特点：

- 中文表头
- 数值口径写在表头里
- 常规采集字段和增强采集字段分层
- 昵称、ID、链接、地区、粉丝数、阅读中位数、互动中位数、报价等基础字段稳定导出
- 增强模式追加详情页字段、近 30 日/90 日合作笔记字段、粉丝画像和笔记表现字段
