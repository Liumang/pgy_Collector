# 授权码生成说明

这个文件夹只给交付方自己使用，不要发给客户。

授权码只需要填写客户名和授权时长，不需要提前知道客户机器码。

从 `Desktop v0.2.0` 开始，正式方向改为使用 `data-console` 里的线上授权管理后台生成授权码。管理端启动时设置：

```bash
PGY_LICENSE_ADMIN_ENABLED=1
```

然后在数据后台的 `授权管理` 页面生成授权码。

`PGY License Generator.app` 和本文件夹里的命令行脚本进入历史调试状态，只用于旧版飞书授权链路排查。

下面的命令行脚本只用于临时调试：只生成旧版签名授权码，不会写入线上授权中心；线上授权版采集助手不会用这里生成的码激活。

## 生成 30 天授权码

```bash
node license-tools/generate-license.mjs --customer "客户名" --days 30
```

## 生成 90 天授权码

```bash
node license-tools/generate-license.mjs --customer "客户名" --days 90
```

## 批量生成 10 个 30 天授权码

```bash
node license-tools/generate-license.mjs --customer "客户名" --days 30 --quantity 10
```

## 指定到期日

```bash
node license-tools/generate-license.mjs --customer "客户名" --expires 2026-12-31
```

## 永久授权

```bash
node license-tools/generate-license.mjs --customer "客户名" --permanent
```

## 注意

- `private-key.pem` 是私钥，不能发给客户。
- 交付给客户的 App 里只有公钥，没有私钥。
- 同一把私钥可以生成无限多个授权码。
- 旧版飞书授权码不预先绑定机器码。机器码会在用户激活成功后通过飞书回传，用于交付统计和排查异常。
- 新版线上授权码由服务端生成随机码，服务端只保存哈希和脱敏码，首次激活时绑定机器码。
